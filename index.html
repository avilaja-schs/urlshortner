This lets the page save links to GitHub for you. Do it once, on your own computer. The key stays only in this browser — it is not saved in any file students can see.

  1. Open github.com/settings/personal-access-tokens/new (sign in if asked).
  2. Token name: Link Maker. Expiration: pick the longest choice (or "No expiration").
  3. Repository access: choose Only select repositories, then pick urlshortner (the repository this site is in).
  4. Permissions: click Add permissions (or open Repository permissions), choose Contents, and set it to Read and write.
  5. Click Generate token. Copy the key (it starts with github_pat_). GitHub shows it only once.
  6. Paste it below and click Save key.
